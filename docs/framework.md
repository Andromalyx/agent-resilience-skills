# Framework

The operational framework has six steps:

1. Interpret the user request.
2. Detect a resilience signal and classify stress level.
3. Run an integrity checkpoint.
4. Choose a recovery pattern and support action.
5. Respond with a truthful next action.
6. Evaluate completion before claiming the task is done.

For the full conceptual model, see `docs/resilience-framework.md`.

For the agent orchestration flow, see `docs/agent-flow.md`.
