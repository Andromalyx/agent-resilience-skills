# Production Checklist

- Define domain-specific activation signals.
- Add eval cases from real failure modes.
- Log tool failures and verification state.
- Log stress level, support action, and completion evaluation.
- Require explicit uncertainty disclosure for unsupported claims.
- Require tradeoff framing when objectives conflict.
- Require refusal and compliant alternatives for dishonest reporting requests.
- Review adapters for platform policy compatibility.
- Monitor completion claims against actual verification events.
