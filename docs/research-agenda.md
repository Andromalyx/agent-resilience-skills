# Research Agenda

Use this agenda to improve Agent Resilience Skills beyond the starter implementation.

## Uncertainty And Truthfulness

- Uncertainty calibration for AI agents.
- Evidence thresholds for factual claims.
- Hallucination prevention under user pressure.
- Verification-before-completion patterns.

## Failure Recovery

- Tool failure taxonomies.
- Retry versus alternate-route decision policies.
- Partial result communication after failed analysis.
- Incident response communication patterns.

## Human-AI Trust

- Trust repair after agent mistakes.
- User frustration handling.
- Non-defensive language patterns.
- Clear apology boundaries without apology loops.

## Decision Support

- Business KPI tradeoff framing.
- Forecast uncertainty and confidence intervals.
- Responsible reporting and analytics ethics.
- Escalation thresholds for high-stakes decisions.

## Evaluation

- Scenario-based resilience evals.
- Rubrics for calm tone, honesty, recovery quality, and completion truthfulness.
- Regression tests for false completion and hidden failure.
- Domain-specific datasets for retail, coding, support, and workflow automation agents.
