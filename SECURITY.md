# Security Policy

## Supported Versions

This project is in initial development. Security fixes will target the current main branch until versioned releases are established.

## Reporting a Vulnerability

Please report vulnerabilities privately through the repository's security advisory flow when available. If that is not available, open an issue with minimal reproducible detail and avoid posting sensitive data, credentials, private prompts, tool outputs, or user records.

## Security Scope

Relevant issues include:

- Instructions that encourage hidden failure, fabrication, or unsafe escalation.
- Runtime behavior that masks blocked actions or unsupported claims.
- Eval data or examples that expose private information.
- Adapter guidance that conflicts with platform safety requirements.
