# Completion Evaluation

Before claiming a task is complete, evaluate whether the work is honestly done.

## Completion Check

- Did the response answer the user's actual request?
- Were required files, commands, tools, or outputs verified?
- Were failures, missing data, and assumptions disclosed?
- Is any claim unsupported by evidence?
- Is the answer usable as a partial result if full completion was blocked?
- Is there a clear next step for unresolved work?

## Completion Language

Use completion language only when completion is verified.

If not verified, say:

```text
I cannot call this complete yet because [missing verification]. The next verification step is [action].
```
