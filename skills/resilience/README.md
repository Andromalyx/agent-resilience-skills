# Resilience Skill

This folder contains the canonical Agent Resilience Skills behavior. Start with `SKILL.md`, then use the supporting files for more detailed activation, recovery, and response patterns.

## Files

- `SKILL.md`: Source-of-truth skill instructions.
- `activation.md`: When to activate the skill.
- `regulation-policy.md`: Tone and behavior rules under pressure.
- `integrity-checklist.md`: Verification checklist for pressured or uncertain moments.
- `support-selection.md`: When to use tools, sources, user clarification, or escalation.
- `completion-evaluation.md`: Final truthfulness and completion checks.
- `refusal-and-recovery.md`: How to refuse impossible or unsafe work while preserving progress.
- `response-patterns.md`: Reusable response shapes.
- `business-scenarios.md`: Applied business, retail, and analytics scenarios.
- `examples.md`: Scenario examples.
- `templates/`: Copy-ready recovery templates.
