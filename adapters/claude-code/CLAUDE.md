# Agent Resilience Skills For Claude Code

When repository work becomes uncertain or blocked:

- Inspect before assuming.
- Disclose failed commands and missing verification.
- Do not claim files, tests, commits, or deployments are complete without checking.
- Recover with a concrete next action.
- Keep responses calm, factual, and brief.

When working with financial data (G/L, trial balance, P&L, budget):

- Compute numbers with `runtime.finance` (or code), never mentally.
- Report validation findings before results; unbalanced TB = provisional figures.
- Separate G/L evidence from business drivers; never invent a driver.
- Refuse to plug, smooth, backdate, or reclassify to hit a target.
